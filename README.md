## 📌 About the Internship

The **Google AI-ML Virtual Internship** was an eight-week learning programme offered through the AICTE–EduSkills Virtual Internship Program. The programme combined structured week-wise learning with practical exposure, weekly assessments, project documentation and assignments where required, and a final assessment test.

The learning plan focused on machine learning and computer vision, progressing from neural networks and TensorFlow to object detection, product image search, and image classification.

The completion certificate identifies the programme as an **AI-ML Virtual Internship** during August–October 2026 and states that it was supported by the **India Edu Program / Google for Developers**.

## 🎯 Objectives

The key learning objectives of the internship were to:

- Understand foundational machine-learning concepts and neural networks using TensorFlow.
- Explore convolutional neural networks for image recognition and classification.
- Learn the fundamentals of object detection and pretrained object detectors.
- Explore custom object-detection models using TensorFlow Lite and Model Maker.
- Understand on-device object detection for product image search.
- Learn how object detection can be used with static images and live camera feeds.
- Explore backend integration for mobile product-search applications.
- Understand custom image-classification models and their integration into applications.
- Complete the required assessments and document learning activities.

## 🗓️ Eight-Week Internship Structure

| Week | Module | Learning Focus |
|---|---|---|
| Week 1 | Program Neural Networks with TensorFlow | Machine-learning fundamentals and convolutional neural networks for image recognition and classification. |
| Week 2 | Get Started with Object Detection | Object-detection basics and integrating pretrained object detectors into mobile apps. |
| Week 3 | Go Further with Object Detection | Training custom object-detection models using TensorFlow Lite and Model Maker. |
| Week 4 | Get Started with Product Image Search | Building a product image-search feature using on-device object detection. |
| Week 5 | Product Image Search | Detecting objects in static images and live camera feeds for visual product search. |
| Week 6 | Advanced Product Image Search | Backend integration for mobile product-search applications. |
| Week 7 | Image Classification | Building custom image-classification models and developing classification skills. |
| Week 8 | Advanced Image Classification | Creating and integrating a custom image-classifier model into an application. |
